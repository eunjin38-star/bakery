# 할아버지의 시그니처 빵 방탈출

GitHub Pages에 그대로 올릴 수 있도록 HTML과 이미지를 분리한 버전입니다.

## 실행 방법

1. 이 폴더 안의 `index.html`과 `assets` 폴더를 함께 GitHub 저장소에 올립니다.
2. GitHub 저장소의 **Settings → Pages**에서 배포할 브랜치를 선택합니다.
3. 로컬에서 시험할 때는 `index.html`을 직접 열거나 VS Code의 Live Server로 실행합니다.

`assets` 폴더의 이름이나 위치를 바꾸면 이미지가 보이지 않으므로 폴더 구조를 그대로 유지하세요.

## 최종 업로드 파일

- `index.html`: 게임 전체 코드
- `assets/images/`: 게임에 사용되는 이미지 14개
- `assets/video/prologue.mp4`: 프롤로그 영상 1개

MP3 오디오 파일은 사용하지 않습니다. GitHub에는 이 폴더의 구조를 바꾸지 말고 그대로 올리세요.

## 클릭 조사 방식

- 메인홀: 칠판, 빵 액자, 벽 메모, 주방 문, 카운터
- 카운터: 서랍과 휴대폰
- 주방: 오븐, 재료 선반, 냉장고, 조리대, 개수대, 달걀, 밀가루통 아래
- 진행에 필요한 단서는 앞 단계를 해결한 뒤 활성화됩니다.
- 획득한 열쇠는 인벤토리에서 주방 문으로 드래그해야 사용할 수 있습니다.

## 이미지 교체

같은 파일명으로 이미지를 교체하면 HTML 코드를 수정하지 않아도 됩니다. 화면 비율과 크기는 기존 이미지와 동일하게 유지하는 것이 좋습니다.
